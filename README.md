- [opsatlas](https://github.com/JVCSampaio/opsatlas): procedimentos técnicos. Responde com o trecho e a revisão da fonte, e se abstém quando o acervo não tem a resposta. Busca lexical, RAG opcional e Kubernetes no CI.
